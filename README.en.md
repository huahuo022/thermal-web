# thermal-web

A tiny self-hosted web UI for ESC/POS thermal receipt printers.
**Zero third-party dependencies** - Python 3 standard library only.

Unlike a CUPS-based front end (upload a file, let Ghostscript rasterise it into a
bitmap), thermal-web talks ESC/POS to the printer directly.  That keeps text
crisp (native printer fonts, no server side fonts needed), makes jobs fast and
light, and exposes the commands receipts actually use: cut, cash drawer, buzzer
and code page selection.

## Features

- Text printing through the printer's own code page (GBK / GB18030 / BIG5 / CP437),
  with alignment, character size, bold, underline, invert and font A/B
- Image printing dithered **in the browser** (threshold, Floyd-Steinberg, Atkinson)
  so the preview is bit-for-bit what the printer burns - no Pillow required
- Native QR (`GS ( k`) and barcodes (CODE128 / EAN13 / CODE39 / UPC-A / ITF)
- Block based receipt builder with JSON import/export and live preview
- Print history with one click reprint (raw bytes are stored)
- Targets: `device:/dev/usb/lp0`, `socket:host:9100`, `cups:queue`
- Dry run: show the ESC/POS byte count and hex dump without wasting paper

## Install

```bash
git clone https://github.com/huahuo022/thermal-web.git
cd thermal-web
sudo ./install.sh          # installs to /opt/thermal-web, listens on 8080
```

Or run it directly:

```bash
python3 server.py --port 8080 --data ./data
```

## API

```bash
curl -s localhost:8080/api/print -H 'Content-Type: application/json' -d '{
  "kind": "text", "text": "Hello\nTotal: 12.00", "align": "center", "size": "double"
}'
```

`POST /api/print` accepts `kind` of `text`, `qr`, `barcode`, `bitmap`,
`image-file` or `receipt` (a list of blocks).  Add `"dry_run": true` to get the
generated byte stream instead of printing it.
